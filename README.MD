# BMP-WATERMARK-PROJECT

Программа на C++ для наложения цифрового водяного знака
на BMP-изображение.


## Описание проекта

Командный проект, реализующий чтение, обработку, наложение
и сохранение BMP-изображений.

Программа принимает на вход 2 файла (`original.bmp` и
`watermark.bmp`) — исходное изображение и водяной знак
для исходного изображения.

После выполнения программы она сохраняет новый BMP-файл
с результатом выполнения программы.


**Основные возможности:**

- Чтение несжатых 24-битных BMP-изображений.

- Получение размеров изображения и доступ к пикселям.

- Наложение водяного знака с частичной прозрачностью.

- Сохранение результата в отдельный BMP-файл.

- Обработка ошибок открытия файлов и несовместимых размеров.

## Сборка проекта

**Требования**

Необходимы **CMake 3.24** или новее,
компилятор с поддержкой **C++23** и **GNU Make**.

Для выполнения тестов требуется **Google Test**.

### Сборка на Linux с Clang

**Клонирование репозитория:**

```bash
git clone https://github.com/gl0s3/bmp-watermark-project.git
cd bmp-watermark-project
```

**Конфигурация CMake:**

```bash
cmake -S . -B build -G "Unix Makefiles" \
    -DCMAKE_CXX_COMPILER=clang++
```

**Сборка:**

```bash
cmake --build build
```

После успешной сборки исполняемый файл располагается
по пути `build/bmp_watermark`.


## Использование проекта (примеры) + тестирование

### Запуск проекта

Программа запускается с тремя аргументами:

```bash
./build/bmp_watermark <original.bmp> <watermark.bmp> <output.bmp>
```

Где:

- `original.bmp` — путь к исходному изображению.

- `watermark.bmp` — путь к водяному знаку.

- `output.bmp` — путь для сохранения результата.

**Пример запуска:**

```bash
./build/bmp_watermark \
    examples/original.bmp \
    examples/watermark.bmp \
    result.bmp
```

Программа возьмёт два файла из папки `examples/`
(`original.bmp` и `watermark.bmp`).

Результат сохранится в файл `result.bmp`.

Если один из файлов не открывается или размеры водяного
знака превышают размеры исходного изображения,
программа сообщает об ошибке.


### Тестирование

Тестирование производится с использованием Google Test.

**Локальный запуск тестирования проекта:**

```bash
ctest --test-dir build
```

**Для подробного вывода результатов тестирования:**

```bash
ctest -V --test-dir build
```

**Проверяемая функциональность:**

- Проверка корректности работы класса `Color`.

**Проверки, которые необходимо подтвердить тестами перед сдачей:**

- Проверка корректности работы класса `ImageBMP`.

- Корректность работы чтения и записи заголовков `.bmp`.

- Проверка массивов цветов.

- Проверка наложения водяного знака (функции `ApplyWatermark()`).

- Общая проверка проекта.


### Автоматическое тестирование (CI)

Для автоматической сборки и запуска тестов
используется **GitHub Actions**.

Workflow загружает исходный код, устанавливает
зависимости, собирает проект через CMake и Clang
и запускает тот же набор тестов через CTest.


## Алгоритм наложения

Наложение производится путём смешивания цветовых
компонентов исходного изображения и водяного знака.

Для каждого канала RGB применяется **формула**:

$C_{\text{result}} = (1 - \alpha) \cdot C_{\text{original}} + \alpha \cdot C_{\text{watermark}}$

Где:

- $\alpha$ — коэффициент непрозрачности водяного знака.
  В проекте использовалось значение $\alpha = 0.3$,
  то есть 70% оригинального пикселя и 30% пикселя
  водяного знака.

- $C_{\text{watermark}}$ — компонент цвета водяного знака.

- $C_{\text{original}}$ — компонент цвета исходного изображения.

Положение водяного знака: **указать в соответствии
с окончательной реализацией `ApplyWatermark()`**.


## Примеры работы

Для проверки результата используются следующие файлы:

- `examples/original.bmp` — исходное изображение.

- `examples/watermark.bmp` — водяной знак.

- `examples/expected.bmp` — ожидаемый результат наложения.

После запуска программы необходимо сравнить
полученный файл с ожидаемым результатом и убедиться,
что исходное изображение остаётся видимым.
